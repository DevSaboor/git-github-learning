### Exercise 1 — Terminology & System Distinction

**Goal**  
Solidify the conceptual difference between local version control (Git) and cloud hosting (GitHub).

**Starting point**  
A blank sheet of paper or notes app.

**Steps**
1. Write down whether the following actions require `Git`, `GitHub`, or `Both`:
   - Saving a snapshot of your code on your laptop while offline.
   - Sharing a link to your project repository with a remote teammate.
   - Reverting a file back to yesterday's state on your local machine.

2. Check your answers against the core definitions below.

<details>
<summary><b>Click to reveal Answers</b></summary>

| Action | Tool Required | Why |
| --- | --- | --- |
| Saving a snapshot of your code on your laptop while offline | **Git** | Git works locally. No internet needed. |
| Sharing a link to your project repository with a remote teammate | **GitHub** | GitHub hosts the repo in the cloud so others can access it. |
| Reverting a file back to yesterday's state on your local machine | **Git** | `git checkout` / `git restore` works on your local history. |

</details>

**What this teaches**  
Distinguishing between **local operations** handled by Git and **cloud operations** handled by GitHub.
