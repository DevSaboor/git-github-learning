# Git & GitHub Learning

A structured, beginner-friendly journey of learning **Git and GitHub from scratch** through theory, hands-on practice, and real-world workflows.

The goal of this repository is simple:

> **Learn Git and GitHub by actually using Git and GitHub, while creating documentation that another beginner can follow from zero.**

---

## 📚 Learning Resources

The primary learning source is CodeWithHarry's Git & GitHub course, supported by his:

* Git & GitHub Handbook
* Git & GitHub Cheatsheet

The **video is the primary learning path**, while the handbook and cheatsheet are used to reinforce concepts, clarify explanations, and reference commands.

## 📝 What Each Chapter Contains

Depending on the topic, a chapter may contain:

* **Notes** — Concepts explained in beginner-friendly language
* **Examples** — Commands and workflows demonstrated during learning
* **Practice** — Hands-on exercises to reinforce the concepts
* **Key Takeaways** — Important points for revision

The documentation is based on the learning material but written to be understandable without requiring the original course.

---

## 🧪 Learning Through Practice

This repository is not intended to be a collection of copied notes.

The learning process is:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Document
  ↓
Commit
  ↓
Repeat
```

Whenever possible, concepts are practiced directly using Git rather than only being documented theoretically.

## 🎯 Goal

By the end of this journey, I want to be able to:

* Understand how Git works
* Use Git confidently from the command line
* Manage repositories and commits
* Work with branches and merges
* Understand and resolve merge conflicts
* Use GitHub for hosting and collaboration
* Work with Git through GUI tools such as GitHub Desktop and VS Code
* Understand modern Git workflows
* Use Git as part of normal software development

More importantly, I want this repository to remain useful as a **reference for myself and a learning resource for other beginners**.
